## 账户与登录

<AccordionGroup>
  <Accordion title="如何登录 Volink?">
    点击右上角的 **登录**,输入您的**邮箱地址**和**验证码**,然后点击 **登录**。
  </Accordion>

  <Accordion title="如何查看我的点数消耗?">
    打开 **仪表盘** 查看今日和最近 30 天的 **消耗积分**、**请求数**、**Tokens** 和 **延迟**。如需查看每次请求的明细,请打开 **日志**。
  </Accordion>

  <Accordion title="如何购买点数?">
    在左下角 **积分余额** 区块中点击 **充值**,然后选择您想要的**套餐**。
  </Accordion>

  <Accordion title="Volink 支持哪些付款方式?">
    您可以使用**信用卡**或**支付宝**支付套餐费用。
  </Accordion>
</AccordionGroup>

    - MiniMax: Speech 02 Turbo
    - ByteDance: Open Speech TTS v3

  </Accordion>

  <Accordion title="如何获取用于文本和语音的 API 密钥?">
    单个 API 密钥可访问所有 Volink 文本和语音模型。

    1. 在左侧边栏中点击 **API 密钥**。
    2. 点击蓝色的 **创建 API 密钥** 按钮。
    3. 在弹出窗口中输入**密钥名称**,然后点击 **创建** 生成密钥。

    <Warning>
      创建后立即复制并保存您的 API 密钥 —— 您将无法再次查看它。
    </Warning>

    您可以为不同的项目或环境创建多个 API 密钥。
  </Accordion>
</AccordionGroup>

## 语音功能

<AccordionGroup>
  <Accordion title="如何创建混音?">
    混音结合了多个语音角色,以创建独特的对话效果。

    1. 点击 **创建我的语音**。
    2. 点击 **混音**。
    3. 输入**名称**并选择**模型**。
    4. 点击 **添加语音**。
    5. 选择语言和性别。
    6. 输入**试听文本**。
    7. 点击 **仅保存声音,无试听**。

    要进行更高的自定义,请在混音页面打开 **设置** 以调整精确参数。
  </Accordion>

  <Accordion title="如何创建文本设计声音?">
    文本设计声音使用文本描述生成自定义语音。

    1. 点击 **创建我的语音**。
    2. 点击 **文本设计声音**。
    3. 输入**名称**并选择**模型**。
    4. 输入**描述语音的提示词**。
    5. 输入**试听文本**。
    6. 点击 **仅保存声音,无试听**。
  </Accordion>

  <Accordion title="如何创建语音克隆?">
    语音克隆从录制的音频样本中复制音调,以重新创建自定义语音。

    1. 点击 **创建我的语音**。
    2. 点击 **语音克隆**。
    3. 输入**名称**并选择**模型**。
    4. 上传**音频文件**。
    5. 选择语言和性别。
    6. 输入**试听文本**。
    7. 点击 **仅保存声音,无试听**。
  </Accordion>
</AccordionGroup>

## 故障排除

<AccordionGroup>
  <Accordion title="错误代码 401 是什么意思?">
    `401` 状态代码表示您的请求未经授权。请验证您的 API 密钥是否正确,并已包含在 `Authorization` 标头中,格式为 `Bearer YOUR_VOLINK_API_KEY`。
  </Accordion>

  <Accordion title="错误代码 404 是什么意思?">
    `404` 状态代码表示未找到端点、模型或资源。请检查请求中的端点路径和模型 ID。

    对于语音请求,请确认您账户中存在该语音 ID。
  </Accordion>

  <Accordion title="错误代码 429 是什么意思?">
    `429` 状态代码表示您已超出当前配额。请检查您的套餐和计费详情,或通过左下角 **积分余额** 区块的 **充值** 按钮购买更多点数。
  </Accordion>

  <Accordion title="温度超出范围错误是什么意思?">
    此错误在 `temperature` 值超出可接受范围时发生。将 `temperature` 设置为 **0** 到 **1** 之间的值。

    <Note>
      不同的模型可能有不同的温度范围。请参阅模型文档以了解确切的支持范围。
    </Note>
  </Accordion>
</AccordionGroup>

---
title: "API 密钥"
description: "了解如何生成、组织和撤销 Volink API 密钥,以在所有受支持的文本和语音模型上对请求进行身份验证。"
---

Volink API 密钥是用于验证您发送到 Volink 网关的每个请求的凭证。一个密钥即可访问所有 Volink 文本和语音模型,因此您只需管理单个凭证即可使用整个平台。

## 创建 API 密钥


<Steps>
  <Step title="打开 API 密钥">
    在 Volink 控制面板的左侧边栏中点击 **API 密钥**。
  </Step>
  <Step title="开始创建密钥">
    点击页面顶部蓝色的 **创建 API 密钥** 按钮。
  </Step>
  <Step title="为密钥命名">
    在弹出对话框中输入描述性的密钥名称,然后点击 **创建**。
  </Step>
  <Step title="复制并保存密钥">
    立即复制生成的密钥字符串,并将其存储在安全位置,例如密码管理器或密钥保险库中。
  </Step>
</Steps>

<Note>
  关闭创建对话框后,您将无法再次查看密钥。请在关闭弹出窗口前复制它 —— 如果丢失,您将需要创建一个新密钥。
</Note>

## 多个 API 密钥

您可以根据工作流程需要创建任意数量的 API 密钥。常见模式是为每个项目或环境创建一个密钥 —— 例如 `production` 密钥和 `development` 密钥 —— 这样您就可以撤销或轮换某个上下文的凭证,而不影响其他上下文。

## 撤销密钥

删除任何您不再需要的密钥。在侧边栏中打开 **API 密钥**,在列表中找到密钥,并使用其旁边的删除操作。撤销未使用的密钥可以在密钥泄露时减少攻击面。

<Warning>
  切勿与他人共享 API 密钥、将其粘贴到聊天中或提交到版本控制。将密钥存储在环境变量或密钥管理器中,以使其远离您的源代码。
</Warning>

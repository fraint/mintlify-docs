Volink 使用基于点数的计费系统。您预先购买一捆点数,每次进行 API 调用时都会消耗这些点数。每次调用扣除的点数数量取决于您使用的模型以及该请求中输入和输出的数量。

## 查看点数使用情况

要查看您在给定时间段内使用了多少点数:

1. 在左侧边栏中点击 **Account**。
2. 选择 **Points**,然后点击 **Usage** 选项卡。
3. 设置**开始日期**和**结束日期**以过滤该范围内的历史。

Usage 选项卡显示消耗细分,以便您识别哪些调用使用的点数最多。

<Tip>
  定期监控您的使用情况。在项目启动或高流量期之前检查 Usage 选项卡,有助于避免在部署中途出现意外的配额耗尽。
</Tip>

## 购买点数

当您的点数余额不足时,可直接从控制面板充值:

1. 在点数部分点击 **Top Up**。
2. 选择适合您使用需求的套餐。

## 付款方式

Volink 在购买点数套餐时接受以下付款方式:

- **信用卡**
- **支付宝**

## 了解消耗

每次 API 调用都会消耗点数。具体数量取决于您选择的模型和请求的大小 —— 输入和输出越长,使用的点数越多。使用 **Usage** 选项卡查看您的消耗历史,并识别哪些请求占用了最多的开销。

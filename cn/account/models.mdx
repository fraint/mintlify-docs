Volink 将您的 API 请求路由到多个底层 AI 提供商,使您能够通过单个密钥和基础 URL 访问广泛的模型集合。无需为每个提供商管理单独的凭证,您只需配置一次 Volink,即可使用相同的身份验证调用任何支持的模型。

## 支持的提供商

Volink 当前与以下提供商集成:

- Anthropic
- BytePlus
- DeepSeek
- Google
- MiniMax
- MoonshotAI
- OpenAI
- Qwen
- Z.AI
- X.AI

## 文本模型

以下文本生成模型可通过 Volink 使用:

- Claude (Haiku / Opus / Sonnet)
- Doubao
- DeepSeek (R1 / V3)
- Gemini
- MiniMax
- Kimi
- GPT
- Qwen
- GLM4.6
- Grok

## 语音模型

以下文本转语音模型可通过 Volink 使用:

- MiniMax: Speech 02 Turbo
- ByteDance: Open Speech TTS v3
- SenseTime: Daily Innovation TTS v1
- CosyVoice2-0.5B

<Note>
  模型可用性取决于您的 Volink 账户套餐。登录控制面板查看哪些模型已为您的账户启用。
</Note>

<Tip>
  配置集成时,请使用 Volink 控制面板中显示的精确模型 ID —— 包括大小写。模型 ID 区分大小写,必须完全匹配才能正确路由请求。
</Tip>

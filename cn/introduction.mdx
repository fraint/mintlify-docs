Volink 是一个统一的 AI API 网关,通过单个 API 密钥和基础 URL 将您的请求路由到领先的 AI 提供商 —— 包括 OpenAI、Anthropic、Google、DeepSeek、MiniMax、MoonshotAI、Qwen、X.AI、BytePlus 和 Z.AI。您可以继续使用已经熟悉的 SDK 和客户端代码;Volink 在后台处理身份验证、路由和协议规范化。

## Volink 提供什么

Volink 支持三类 AI API,均可通过您的单个 Volink API 密钥访问:

- **聊天补全** —— 通过 OpenAI 兼容或 Anthropic 兼容协议进行文本生成和工具调用
- **文本转语音** —— 通过 OpenAI Speech 或 Volink TTS 端点进行音频合成
- **图像生成** —— 通过 OpenAI Images API 或 Volink 基于聊天的图像生成端点进行图像创建

## 我应该使用哪种 API 协议?

选择与您已使用的 SDK 或客户端匹配的协议。所有三种协议都使用相同的 Volink API 密钥和基础 URL (`https://api.volink.org`)。

| 协议 | 最适合 | 认证标头 | 聊天端点 |
|---|---|---|---|
| **OpenAI 兼容** | OpenAI SDK、大多数 AI 代理工具和聊天客户端 | `Authorization: Bearer` | `POST /v1/chat/completions` |
| **Anthropic 兼容** | Anthropic SDK、Claude 风格的客户端 | `x-api-key` + `anthropic-version: 2023-06-01` | `POST /v1/messages` |
| **Volink 原生** | Volink 特有功能,如基于聊天的图像生成 | `Authorization: Bearer` | `POST /v1/chat/completions` 配合 `modalities` |

如果您不确定选择哪个,请从 OpenAI 兼容协议开始 —— 它适用于范围最广的工具和 SDK。

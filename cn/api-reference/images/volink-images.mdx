---
title: "通过聊天补全 API 进行 Volink 图像生成"
description: "使用 Volink 的聊天补全端点配合 modalities,从一起返回图像和文本输出的多模态模型生成图像。"
---

Volink 还支持通过聊天补全端点使用 `modalities` 字段进行图像生成。与 OpenAI Images API 不同,此方法适用于可以在单个响应中同时返回图像和文本的多模态模型,例如 Gemini 图像预览模型。

## 端点

```http
POST /v1/chat/completions
```

## 请求参数

<ParamField body="model" type="string" required>
  支持图像功能的模型 ID。使用模型发现端点查找支持图像输出的模型(参见下文)。
</ParamField>

<ParamField body="messages" type="array" required>
  提示消息。以与标准聊天请求相同的方式组织它们 —— 通常是描述您想要的图像的单个 `user` 消息。
</ParamField>

<ParamField body="modalities" type="array" required>
  指定您期望模型输出的类型。对于仅图像模型使用 `["image"]`,或对于同时返回图像和文本输出的模型使用 `["image", "text"]`。
</ParamField>

<ParamField body="image_config" type="object">
  模型特定的图像生成选项,例如纵横比或输出尺寸。支持的键取决于模型。
</ParamField>

<ParamField body="stream" type="boolean">
  当模型支持时,设置为 `true` 以流式传输响应。
</ParamField>

## 示例

```bash
curl "$VOLINK_BASE_URL/v1/chat/completions" \
  -H "Authorization: Bearer $VOLINK_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gemini-2.5-flash-image-preview",
    "messages": [
      {
        "role": "user",
        "content": "Generate a modern dashboard mockup for Volink analytics."
      }
    ],
    "modalities": ["image", "text"],
    "image_config": {
      "aspect_ratio": "16:9"
    }
  }'
```

## 响应

生成的图像在助手消息中返回,通常作为嵌入 `images` 数组中的 base64 数据 URL,与任何文本内容一起:

```json
{
  "id": "gen_xxx",
  "object": "chat.completion",
  "choices": [
    {
      "index": 0,
      "message": {
        "role": "assistant",
        "content": "Here is the generated image.",
        "images": [
          {
            "image_url": {
              "url": "data:image/png;base64,..."
            }
          }
        ]
      },
      "finish_reason": "stop"
    }
  ]
}
```

<ResponseField name="choices[].message.content" type="string">
  助手响应的文本部分。当 `modalities` 包含 `"text"` 时存在。
</ResponseField>

<ResponseField name="choices[].message.images" type="array">
  嵌入在助手消息中的生成图像对象数组。

  <Expandable title="properties">
    <ResponseField name="images[].image_url.url" type="string">
      包含 base64 编码图像的数据 URL,例如 `data:image/png;base64,...`。直接解码或在 `<img>` 标签中渲染。
    </ResponseField>
  </Expandable>
</ResponseField>

## 发现支持图像的模型

使用带有 `output_modalities=image` 查询参数的 `/v1/models` 端点列出所有支持图像输出的模型:

```bash
curl "$VOLINK_BASE_URL/v1/models?output_modalities=image" \
  -H "Authorization: Bearer $VOLINK_API_KEY"
```

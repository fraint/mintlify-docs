Volink 提供与 OpenAI 兼容和与 Anthropic 兼容的 REST API,用于聊天补全、文本转语音和图像生成。您在所有协议中使用相同的 Volink API 密钥,所有请求都发送到相同的基础 URL:`https://api.volink.org`。

## 设置您的环境

在运行本参考中的任何示例之前,请导出您的凭证:

```bash
export VOLINK_API_KEY="your_api_key"
export VOLINK_BASE_URL="https://api.volink.org"
```

## 可用端点

| 端点 | 协议 | 描述 |
| --- | --- | --- |
| `POST /v1/chat/completions` | OpenAI 兼容 | 聊天补全 |
| `POST /v1/messages` | Anthropic 兼容 | 聊天消息 |
| `POST /v1/audio/speech` | OpenAI 兼容 | 文本转语音 |
| `POST /v1/tts/speech` | Volink 原生 | 文本转语音 |
| `POST /v1/images/generations` | OpenAI 兼容 | 图像生成 |
| `GET /v1/models` | OpenAI 兼容 | 列出可用模型 |

有关如何对请求进行身份验证的详细信息,请参阅 [身份验证](/api-reference/authentication)。有关错误代码和响应格式的完整列表,请参阅 [错误](/api-reference/errors)。

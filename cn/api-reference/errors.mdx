Volink 在每个响应中都返回标准 HTTP 状态代码。当请求失败时,响应正文包含一个带有 `error` 字段的 JSON 对象,该字段描述了出错原因。

## 错误响应格式

```json
{
  "error": {
    "message": "Invalid model.",
    "type": "invalid_request_error",
    "code": "model_not_found"
  }
}
```

## 状态代码

| 状态 | 含义 |
| --- | --- |
| `400` | 请求无效。检查请求正文中是否缺少或格式错误的字段。 |
| `401` | 缺失或无效的 API 密钥。验证 `Authorization` 或 `x-api-key` 标头中的密钥。 |
| `402` | 配额不足。向您的 Volink 账户充值以继续。 |
| `403` | API 密钥无权访问所请求的模型或功能。 |
| `404` | 未找到端点、模型或资源。确认路径和模型 ID 正确。 |
| `429` | 超过速率限制。稍后重试。 |
| `500` | 内部服务器错误。如果问题持续存在,请联系 Volink 技术支持。 |
| `503` | 上游提供商不可用或过载。使用指数退避重试。 |

## 备注

- 参数支持可能因模型和上游提供商而异。如果参数被忽略或不受支持,请求仍可能成功完成,但不会应用该选项。
- 流式响应在受支持时使用服务器发送事件 (SSE)。如果您的客户端无法正确处理 SSE,请禁用流式传输并轮询结果。
- 示例中的某些模型 ID 是说明性的。请将它们替换为您 Volink 账户中已启用的模型 ID。
- 对于特定提供商的行为,Volink 在规范化身份验证和路由的同时,尽可能紧密地遵循所选协议。

Volink 是一个统一的 AI 网关,让您能够通过单个 API 密钥调用与 OpenAI 兼容和与 Anthropic 兼容的 API —— 用于聊天、文本转语音和图像生成。无论您是使用现有 SDK 构建、集成 AI 代理工具,还是在聊天客户端中进行实验,Volink 都会将您的请求路由到正确的提供商,而无需您管理多个凭证。

## 工作原理

<Steps>
  <Step title="创建账户并获取您的 API 密钥">
    登录您的 Volink 账户,在侧边栏中导航至 **API Keys**,然后创建一个新密钥。立即复制并妥善保存 —— 之后您将无法再次查看它。
  </Step>
  <Step title="设置环境变量">
    ```bash
    export VOLINK_API_KEY="your_api_key"
    export VOLINK_BASE_URL="https://api.volink.org"
    ```
  </Step>
  <Step title="使用任何兼容的客户端调用 API">
    将 `https://api.volink.org` 作为基础 URL,与您选择的 OpenAI 或 Anthropic SDK 一起使用。同一个密钥可在所有协议中使用。
  </Step>
  <Step title="选择您的集成方式">
    通过 API 直接使用 Volink,或将其连接到 Claude Code、Cursor 或 Cline 等 AI 代理工具 —— 或 LobeChat 或 OpenWebUI 等聊天平台。
  </Step>
</Steps>

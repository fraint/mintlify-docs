---
title: "快速开始"
description: "创建账户、生成 API 密钥、设置环境变量,并向 Volink 统一 AI 网关发送您的首个聊天补全请求。"
---

Volink 为您提供一个 API 密钥和基础 URL,可用于 OpenAI 兼容、Anthropic 兼容和 Volink 原生端点。按照以下步骤,从零开始完成您的首次成功 API 调用。

<Steps>
  <Step title="创建或登录您的账户">
    访问 [volink.org](https://volink.org),点击右上角的 **Log In**。输入您的**邮箱地址**,然后输入发送到该邮箱的**验证码**,并点击 **Log In**。
  </Step>

  <Step title="创建 API 密钥">
    1. 在左侧边栏中,点击 **API Keys**。
    2. 点击蓝色的 **Create API Key** 按钮。
    3. 在弹出对话框中输入密钥名称,然后点击 **Create**。
    4. 立即复制密钥并将其存储在安全的地方。

    <Note>
      您只能在创建后立即查看一次 API 密钥。关闭对话框后,Volink 不会再次显示完整密钥。如果丢失,请创建新的密钥。
    </Note>
  </Step>

  <Step title="设置环境变量">
    在 shell 中将您的 API 密钥和 Volink 基础 URL 设置为环境变量。本指南中的所有 API 调用都使用这些变量。

    ```bash
    export VOLINK_API_KEY="your_api_key"
    export VOLINK_BASE_URL="https://api.volink.org"
    ```
  </Step>

  <Step title="进行首次 API 调用">
    使用 OpenAI 兼容端点发送聊天补全请求。此示例使用 `gpt-4.1`,并要求模型介绍自己。

    ```bash
    curl "$VOLINK_BASE_URL/v1/chat/completions" \
      -H "Authorization: Bearer $VOLINK_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "model": "gpt-4.1",
        "messages": [
          {
            "role": "system",
            "content": "You are a helpful assistant."
          },
          {
            "role": "user",
            "content": "Explain Volink in one sentence."
          }
        ],
        "temperature": 0.7
      }'
    ```
  </Step>

  <Step title="验证响应">
    成功的响应如下所示:

    ```json
    {
      "id": "chatcmpl_xxx",
      "object": "chat.completion",
      "created": 1710000000,
      "model": "openai/gpt-4.1",
      "choices": [
        {
          "index": 0,
          "message": {
            "role": "assistant",
            "content": "Volink lets developers access multiple AI models through unified APIs."
          },
          "finish_reason": "stop"
        }
      ],
      "usage": {
        "prompt_tokens": 20,
        "completion_tokens": 12,
        "total_tokens": 32
      }
    }
    ```

    如果您收到 `401` 错误,请检查 `VOLINK_API_KEY` 变量是否正确设置。如果您收到 `404`,请确认 `VOLINK_BASE_URL` 已设置为 `https://api.volink.org`。
  </Step>
</Steps>

<Tip>
  请查阅 [API 参考](/cn/api-reference/overview) 了解所有可用端点,包括 Anthropic 兼容聊天、文本转语音和图像生成。
</Tip>

Volink 为每个 API 响应返回标准 HTTP 状态代码。当请求失败时,响应正文包含描述出错原因的结构化错误对象。使用此页面识别错误原因并解决问题。

## HTTP 状态代码

| 状态 | 含义 | 如何解决 |
| --- | --- | --- |
| `400` | 请求无效 | 检查请求正文格式,并验证所有必填字段是否存在且类型正确 |
| `401` | 缺失或无效的 API 密钥 | 验证您的 API 密钥是否正确,并已包含在 `Authorization` 标头中,格式为 `Bearer YOUR_VOLINK_API_KEY` |
| `402` | 配额不足 | 通过账户中的 **Top Up** 购买更多点数 |
| `403` | 访问被拒绝 | 您的 API 密钥无权访问此模型或功能 |
| `404` | 未找到 | 检查端点路径和模型 ID |
| `429` | 超过速率限制 | 降低请求频率或升级您的套餐 |
| `500` | 内部服务器错误 | 重试请求;如果错误持续存在,请联系技术支持 |
| `502` / `503` | 上游提供商错误 | 切换到不同的模型或稍后重试 |

## 错误响应格式

来自 Volink 的每个错误响应都遵循此 JSON 结构:

```json
{
  "error": {
    "message": "Invalid model.",
    "type": "invalid_request_error",
    "code": "model_not_found"
  }
}
```

- `message` —— 错误的人类可读描述。
- `type` —— 错误的类别 (例如,`invalid_request_error`)。
- `code` —— 标识特定错误的机器可读代码。

## 常见问题

**温度超出范围**

如果您收到关于 `temperature` 的错误,则您提供的值超出了可接受范围。将 `temperature` 设置为 **0** 到 **1** 之间的数字。请注意,不同的模型可能支持不同的温度范围;请查看模型文档以了解具体限制。

**未找到语音 ID (404)**

如果语音请求返回 `404`,则您请求中指定的语音 ID 在您的账户中不存在。请打开 Volink 控制台的 **Voice** 部分,并确认语音 ID 正确且已创建。

**文本过长 (413)**

如果输入文本过长无法合成,请缩短输入文本的长度或降低请求中的 `max_tokens` 限制。

<Tip>
  如果您收到 `503`,可能是上游提供商过载。在提供商恢复期间,尝试切换到另一个模型。
</Tip>

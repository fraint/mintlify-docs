Volink is a unified AI gateway that lets you call OpenAI-compatible and Anthropic-compatible APIs — for chat, text-to-speech, and image generation — all through a single API key. Whether you're building with an existing SDK, integrating an AI agent tool, or experimenting in a chat client, Volink routes your requests to the right provider without requiring you to manage multiple credentials.

## How it works

<Steps>
  <Step title="Create an account and get your API key">
    Sign in to your Volink account, navigate to **API Keys** in the sidebar, and create a new key. Copy and store it securely — you won't be able to view it again.
  </Step>
  <Step title="Set your environment variables">
    ```bash
    export VOLINK_API_KEY="your_api_key"
    export VOLINK_BASE_URL="https://api.volink.org"
    ```
  </Step>
  <Step title="Call the API with any compatible client">
    Use `https://api.volink.org` as your base URL with the OpenAI or Anthropic SDK of your choice. The same key works across all protocols.
  </Step>
  <Step title="Choose your integration">
    Use Volink directly via API, or connect it to an AI agent tool like Claude Code, Cursor, or Cline — or a chat platform like LobeChat or OpenWebUI.
  </Step>
</Steps>

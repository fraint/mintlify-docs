Volink provides OpenAI-compatible and Anthropic-compatible REST APIs for chat completions, text-to-speech, and image generation. You use the same Volink API key across every protocol, and all requests go to the same base URL: `https://api.volink.org`.

## Set up your environment

Export your credentials before running any examples in this reference:

```bash
export VOLINK_API_KEY="your_api_key"
export VOLINK_BASE_URL="https://api.volink.org"
```

## Available endpoints

| Endpoint | Protocol | Description |
| --- | --- | --- |
| `POST /v1/chat/completions` | OpenAI-compatible | Chat completions |
| `POST /v1/messages` | Anthropic-compatible | Chat messages |
| `POST /v1/audio/speech` | OpenAI-compatible | Text-to-speech |
| `POST /v1/tts/speech` | Volink-native | Text-to-speech |
| `POST /v1/images/generations` | OpenAI-compatible | Image generation |
| `GET /v1/models` | OpenAI-compatible | List available models |

For details on how to authenticate your requests, see [Authentication](/api-reference/authentication). For a full list of error codes and response formats, see [Errors](/api-reference/errors).

Volink routes your API requests to multiple underlying AI providers, giving you access to a broad set of models through a single key and base URL. Instead of managing separate credentials for each provider, you configure Volink once and call any supported model using the same authentication.

## Supported providers

Volink currently integrates with the following providers:

- Anthropic
- BytePlus
- DeepSeek
- Google
- MiniMax
- MoonshotAI
- OpenAI
- Qwen
- Z.AI
- X.AI

## Text models

The following text generation models are available through Volink:

- Claude (Haiku / Opus / Sonnet)
- Doubao
- DeepSeek (R1 / V3)
- Gemini
- MiniMax
- Kimi
- GPT
- Qwen
- GLM4.6
- Grok

## Voice models

The following text-to-speech models are available through Volink:

- MiniMax: Speech 02 Turbo
- ByteDance: Open Speech TTS v3
- SenseTime: Daily Innovation TTS v1
- CosyVoice2-0.5B

<Note>
  Model availability depends on your Volink account plan. Log in to your dashboard to see which models are enabled for your account.
</Note>

<Tip>
  When configuring integrations, use the exact model ID — including capitalization — as shown in your Volink dashboard. Model IDs are case-sensitive and must match precisely for requests to route correctly.
</Tip>
